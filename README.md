Sea Resume 基于 Vue 3 与 TypeScript 构建，支持管理多份简历、切换排版模板、编辑内容与主题，以及导入导出多种文件格式。基础编辑功能无需配置 AI 服务即可使用。

## 快速开始

准备 Node.js 22.12+ 和 pnpm，在项目目录执行：

```sh
pnpm install
pnpm dev
```

打开终端输出的本地地址，默认是 `http://localhost:3000`；端口被占用时以实际输出为准。

1. 在工作台点击 **新建简历**，浏览并预览模板，创建一份简历。
2. 在编辑器填写基础信息，逐步添加经历、项目、教育和技能；用章节快速跳转整理内容。
3. 使用 **质量检查** 查看待补充项目；修改内容后可用撤销/重做，顶部会显示保存状态，失败时可重试。
4. 在 **主题设置** 查看 A4 页数估算，必要时尝试一页适配；通过预览检查后，从 **导入与导出 → 导出为 PDF** 打开打印面板，选择 **A4** 和 **存储为 PDF**。多页内容会按浏览器打印分页规则输出。
5. 工作台的 **岗位版本与比较** 可从简历创建独立岗位副本、记录目标公司/岗位并比较字段差异。
6. **全量备份** 导出当前存储位置全部简历；恢复前会列出 ID/名称冲突，冲突项以新 ID 创建副本，不覆盖已有内容。单份 JSON 恢复仍会创建副本。
7. 需要辅助润色时打开 **AI 助手**，配置服务并审核修改建议。

已有内容可从工作台 **导入 Markdown** 或 **AI 导入 PDF** 开始。PDF 文本先在浏览器本地提取；可校对基础信息、经历和技能等字段后创建新简历。只有勾选同意并发起解析时，提取出的文本和文件名才会发送给所配置的 AI 服务。

## 数据与存储

工作台 **设置** 管理存储位置和单份简历备份；工作台顶部的 **全量备份** 可导出或恢复当前存储位置的所有简历。

![存储设置：本地目录迁移与单份简历备份](docs/images/storage-settings.jpg)

- **浏览器存储**：默认将简历保存在当前浏览器中。清理站点数据可能导致简历丢失，建议定期使用全量备份并将文件保存在安全位置。
- **本地目录**：在工作台的 **设置** 中选择并授权目录。空目录会复制当前简历；已有 Sea Resume 数据的目录可增量合并，同 ID 冲突保留目录中的版本。该功能依赖浏览器的 File System Access API；入口是否可用以当前浏览器检测结果为准。
- **单份 JSON 恢复**：导入后创建简历副本，不覆盖已有数据。
- **全量备份恢复**：备份带格式版本信息，恢复前先验证文件并显示待导入数量及 ID/名称冲突；冲突项以新 ID 和独立名称创建副本，绝不覆盖现有简历。浏览器会在从未备份或距上次全量备份满 30 天时提醒；备份时间戳保存在当前浏览器。
- **PDF 导入**：支持可复制文本的 PDF，最大 15 MB、最多 30 页；扫描图片 PDF 暂不支持 OCR。原 PDF 不上传；用户明确同意后，仅提取文本和文件名会发送给所配置的 AI 服务，确认前可校正识别内容。
- **AI 请求**：仅在用户确认并发起请求时向所配置的服务发送内容。出生日期不会随 AI 助手请求发送。API Key 仅保存在页面会话内存中；记住配置只保存服务商预设、服务地址和模型名称。

## 开发与验证

| 命令 | 用途 |
| --- | --- |
| `pnpm dev` | 启动 Vite 开发服务器 |
| `pnpm build` | 执行 Vue / TypeScript 类型检查并构建生产资源 |
| `pnpm preview` | 本地预览生产构建 |
| `pnpm test` | 执行 Vitest 测试 |
| `pnpm test:watch` | 以监听模式运行测试 |

```sh
pnpm build
pnpm test
```

技术栈：**Vue 3、TypeScript、Pinia、Vue Router、Element Plus、Tailwind CSS、SCSS、Vite、Vitest**。PDF 与图片导出使用 html2canvas / jsPDF，PDF 文本提取使用 PDF.js。

```text
src/
├── views/                 # 工作台、模板库、编辑器
├── components/            # 内容编辑、模板预览与通用组件
├── stores/                # 简历、模板、工作台与存储状态
├── services/ai/           # AI 服务、配置与 PDF 导入
├── services/storage/      # 浏览器与本地文件系统存储
├── utils/                 # 导出、Markdown 解析与隐私打码
└── types/                 # 简历、存储与 AI 类型定义
docs/
├── images/                # README 实际界面截图
└── ui-guidelines.md       # 应用界面样式与交互约定
```

生产构建输出到 `dist/`。项目使用 Vue Router 的 history 模式，部署到静态服务器时需将应用路由回退到 `index.html`，保证刷新编辑器和模板库页面时正常加载。

## 样式与交互约定

全站界面 token、头部、表单、弹层、危险操作和响应式规范见 [UI 设计与交互规范](docs/ui-guidelines.md)。应用界面与五种 A4 简历模板分别维护；模板排版和用户主题由各模板及简历数据负责，不套用应用界面的全局重置。
