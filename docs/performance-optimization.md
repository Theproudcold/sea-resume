# 编辑器性能与平滑交互优化

## 实现

- 表单字段立即通过 action 更新，不再深度监听并 JSON 复制整个条目列表；技能分隔文本保留本地草稿。
- 文本/富文本保存采用 500ms 停顿合并、2s 最长等待。离散操作立即保存；未开始的后台写入合并，显式保存保留 FIFO 屏障。
- 离开编辑页、切换简历、导出前 flush；失败阻止静默离开。页面隐藏时尽力保存，浏览器强制退出不能保证异步写入完成。
- 撤销、重做及导入失败只在没有后续编辑时回滚，避免慢保存失败覆盖新输入。
- 分页观察正文而非自身标记，持久 A4 标尺缓存物理高度，每帧最多一次测量，隐藏时跳过，尺寸/字体/图片变化后补测。
- 编辑模块使用最多 6 项 KeepAlive 缓存，按简历和模块隔离；删除模块清理缓存，顶部添加动作仍指向当前编辑器。
- 120ms 反馈、180ms 切换、200ms 折叠；可中断反转，恢复自然高度，支持减少动态效果与打印。
- AI、导入、版本和备份首次打开时才加载，之后保留实例；加载失败可重试而无需刷新。html2canvas 在图片导出时才加载。

## 验证环境与方法

- Node.js 22.21.1；默认 Node 18 不满足当前 Vite 要求，未改项目依赖。
- 使用相同本机 Google Chrome、1600×1000 视口、production build、独立浏览器上下文和合成简历，避免修改用户数据。
- 1、3、8 页样本按实际 A4 画布高度校准，包含富文本及头像。每轮输入 32 字符，字符间隔 40ms，停顿 700ms 后记录写入次数。
- 输入延迟为捕获 input 到后续双 rAF 回调的间隔，不是浏览器 INP；滚动为约 700ms 脚本滚动中的 rAF 帧间隔，不是人工流畅度评审。
- 返回模块检查同一个真实 Quill DOM 实例是否保留。DOM 重新插入不等于组件重新挂载，不用插入次数冒充挂载次数。

## 结果

| 场景 | 优化前 | 优化后 |
| --- | --- | --- |
| 32 字符整份保存次数，1/3/8 页 | 32 / 32 / 32 | 1 / 1 / 1 |
| 输入期间 A4 标尺布局读取，1/3/8 页 | 27 / 33 / 32 | 0 / 0 / 0（初次测量后缓存） |
| 返回模块保留原 Quill 实例 | 否 | 是 |
| 输入双帧延迟 P95，1/3/8 页 | 未据单轮噪声计算提升比例 | 30.8 / 31.4 / 33.4ms |
| 滚动帧间隔 P95，1/3/8 页 | 不据此声称提升 | 16.7 / 16.7 / 16.7ms |

工作台入口自身 JS 分块从约 511.51kB 降至约 22.61kB（未压缩），PDF 导入移入独立分块。这不是首屏总下载体积：共用入口/Element Plus 等仍较大，构建仍有大分块提示。本轮不扩展到 UI 库全面按需注册。

实际网络请求确认：工作台初次加载不请求 AI 助手、PDF 导入、版本、备份和 html2canvas 分块；打开 AI 助手后才加载其分块。

## 并行改动与限制

实施期间工作区另有面试与 AI 优化功能改动，已保留，未覆盖或回退。其未完成时曾阻断全量构建；最后一次整仓库检查已恢复为 **50 个测试文件、238 项测试通过，`pnpm build` 通过，`git diff --check` 通过**。隔离性能快照仍为 179 项测试，浏览器性能及交互数据基于该快照，不代表并行面试功能已由本任务完成浏览器验收。

内置浏览器面板未能显示，浏览器检查改用本机无头 Chromium。未进行真实移动设备、其他浏览器或人工动画视觉验收，不承诺所有设备固定 60fps。性能基线、产物和下载文件保存在会话临时目录，不将临时输出写入项目。
