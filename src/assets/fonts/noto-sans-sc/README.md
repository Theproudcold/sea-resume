# Noto Sans SC fonts

These Simplified Chinese OpenType fonts are distributed under the SIL Open Font License 1.1. The complete license is in `LICENSE`.

Source: [notofonts/noto-cjk](https://github.com/notofonts/noto-cjk/tree/main/Sans/SubsetOTF/SC)

- `NotoSansSC-Regular.otf` — 8,331,336 bytes
- `NotoSansSC-Bold.otf` — 8,543,168 bytes

They are emitted as separate Vite assets and fetched only on the first searchable-PDF export. pdfmake subsets embedded glyphs; a smoke-test PDF containing Chinese and Latin text was approximately 42.6 KB.
